# LuMate · 噜伴

**你的 AI 助手在忙，你的桌面有伴。**

<img src="docs/assets/lumate-pets.png" alt="LuMate 的两只内置宠物：挎包噜噜和粉裙噜妹并排站立" width="520" />

面向 **macOS** 的桌面宠物与 AI 编程状态伴侣。<br />
内置噜噜和噜妹，也支持选择、导入其他宠物。

**macOS 14+ · Swift 6 · 本地 Token 统计 · 一个菜单栏入口**

## 认识噜噜和噜妹

| 噜噜 | 噜妹 |
| :---: | :---: |
| <img src="docs/assets/lulu.png" alt="噜噜：背着绿色挎包的黄色小伙伴" width="144" /> | <img src="docs/assets/lumei.png" alt="噜妹：戴着小帽、穿着粉色裙子的黄色小伙伴" width="144" /> |
| 背上小挎包，陪你开工。 | 穿上小粉裙，安静陪在身边。 |

**Lu** 来自噜噜与噜妹，**Mate** 是伙伴；连起来读，也有一点“噜妹”的谐音。

它们是 LuMate 的两位内置伙伴，不是仅有的选择：你可以切换其他外观，也可以导入自己的宠物。**切换形象不清空成长；新建宠物会创建独立档案**，旧宠物仍可切回。噜噜与噜妹均提供待机和戳戳、被戳、抱抱、探头互动动画。

> **版本状态：** 当前版本为 **v0.2.5（2026-11-06）**，新增「回窝睡觉 / 出窝搬砖」，共享屏幕时收起桌宠与提醒，后台继续收信；保留双宠互动回放、应用内更新和多消息展开等功能。安装包见 [GitHub Releases](https://github.com/stivelcn/lumate/releases)；本项目版本号独立于上游项目。

## 不只是桌宠

| 功能 | 说明 |
| --- | --- |
| 桌宠与项目 | 管理宠物、关联项目，通过状态气泡查看编程助手正在做什么 |
| 会话与提醒 | 查看会话状态、保留完成提醒，并跳转到对应终端或会话 |
| 本地 Token 统计 | 用量历史、日/月统计与日历热力图；只统计 Token，不估算费用 |
| 近七天趋势 | 右键宠物查看每日趋势，悬停显示完整日期和准确 Token 数量 |
| 刘海火焰 | 随实时输出变化，支持开关、颜色梯度、六项外观参数与原生预览编辑 |
| 实时输出速度 | 在菜单栏查看 `token/s`，可设置显示开关及小数位数 |
| 双人传话（未发布） | 6 位配对码，20 字短消息和小图标；未读气泡手动关闭或回复后消失，离线可补收 |
| 陪伴与养成 | 独立宠物档案、成长、成就、休息提醒，以及安静的待机与眨眼动画 |

支持 Claude Code、Codex、Gemini CLI、Cursor、opencode 等编程助手的本地事件接入与日志解析。不同客户端提供的信息和连接方式不同，以应用连接设置为准；并非所有客户端都经过相同程度的实机验证。

## 在 Mac 上运行

### 环境要求

- **macOS 14 或更新版本**。
- **Swift 6** 与匹配的 macOS SDK，可使用相应版本的 Xcode 或 Command Line Tools。
- 仓库包含所需的本地依赖源码，无需另外安装 EmberCat 或 Agent Speed。

### 从源码启动

```bash
git clone https://github.com/stivelcn/lumate.git
cd lumate
./scripts/dev.sh run
```

构建成功后启动 `build/LuMate Dev.app`。以后修改代码，运行同一条命令即可重新构建并重启本仓库的开发实例，不需要反复打 DMG 安装。

> **首次启动：** 应用默认检测已安装的编程助手并配置连接。写入前会备份客户端配置，保留其他回调；客户端要求的信任或权限确认仍由你完成。只看界面、不改真实客户端配置时，用下面的命令。

```bash
AGENTPET_ENABLE_DEV_HOOKS=0 ./scripts/dev.sh run
```

### 从旧名称升级

LuMate 保留原 Bundle ID、偏好和数据目录，**同类型构建的宠物、Token 历史与养成不用搬家**；开发版和正式版仍各自独立。

由于 `.app` 路径改变，已有连接请先在**旧版设置中断开编程助手连接并退出旧版**，再启动 LuMate 重新连接；客户端如要求重新信任命令，请核对新路径并自行确认。不会静默覆盖旧 Hook 或修改客户端安全规则。登录启动项与详细兼容边界见 [本地开发说明](LOCAL_DEVELOPMENT.md#从-agentpet-local-升级到-lumate)。

内部 `agentpet` 可执行文件、`AgentPetCore` 模块与 `AGENTPET_*` 环境变量保留兼容名称，不代表界面尚未改名。

### 基本使用

1. 从菜单栏小爪子打开设置，管理宠物、项目和编程助手连接。
2. 编程助手运行时，从桌宠气泡查看进展；按需打开刘海火焰与实时速度。
3. 右键宠物查看统计，悬停近七天图表查看当日 Token 数量。
4. 在历史与养成界面查看长期记录、热力图和宠物成长。
5. 想和另一位伙伴传话，可在设置中配对，然后直接从桌宠旁发送或回复。

### 构建、测试与打包

```bash
./scripts/dev.sh build           # 构建开发包，不启动
./scripts/test.sh                # 隔离数据和偏好的回归测试
./scripts/release.sh native      # 当前 Mac 架构的本地 DMG
./scripts/release.sh universal   # arm64 + x86_64 通用 DMG
```

正式包为 `build/LuMate.app`，安装包为 `build/LuMate-<版本>-<架构>.dmg`。构建与测试统一通过 `scripts/swiftpm.sh` 处理项目级工具链兼容，不建议直接运行裸 `swift build`。

DMG 默认使用本地 ad-hoc 签名，**不等于经过 Apple 公证**。GitHub Actions 仅支持手动生成构建产物，不自动发布 Release；签名、公证和分发说明见 [打包文档](docs/RELEASING.md)。

要验证打包而不替换默认应用包，可以指定独立输出目录：

```bash
./scripts/build-app.sh debug native /tmp/lumate-package-check
```

## 检查与安装更新

菜单栏面板点「检查更新」，或进入设置 →「关于」→「软件更新」。应用读取本仓库 GitHub 最新正式 Release，展示版本和说明，下载经过 SHA-256 校验的当前架构/通用 DMG。支持进度、取消、失败重试和在 Finder 中显示。

下载完成后点「安装并重启」：重新校验 DMG、应用标识/版本/架构/签名，再备份旧应用并替换；需要时由 macOS 请求管理员授权。只替换 `.app`，不删除用户数据目录、偏好或钥匙串。保存失败、未发送输入未关闭、包损坏或签名不符会停止安装。旧应用备份在原应用同目录的隐藏 `.LuMate-backup-*.app`，偏好快照/安装日志在 `~/Library/Caches/local.agentpet/Updates/`。

**开发版不会被正式版覆盖**，直接从 DMG 或 App Translocation 运行时也不能原位更新，请先安装正式版到「应用程序」。本地 ad-hoc 包不等于已公证版本；首次启动或配对钥匙串访问仍可能需要用户本人通过 macOS 安全提示授权。老的 v0.2.0 没有更新入口，首次升级到含更新功能的版本仍需手动安装。构建/发布约定见 [分发说明](docs/RELEASING.md)。

## 桌宠双人传话

设置的「传话」只管理昵称、配对和连接。一方生成配对码，另一方输入同一个配对码请求配对，创建者确认后即可传话。

日常发送：**单击桌宠**，宠物旁直接弹出轻量输入框；未配对时先打开传话设置。右键「给对方传话」入口仍保留。收到消息后点击气泡的「回复」也在桌宠旁完成，不打开设置；支持回车发送、Esc/关闭按钮/点击外部取消，小图标一键发送。取消输入不清除原消息。

- 配对码固定 **6 位，同时含字母和数字，不区分大小写**，10 分钟有效，仅限两台设备。
- 每条文字最多 20 个字符（中文和组合 emoji 按可见字符计数）；支持爱心、喝水、吃饭、休息、抱抱、看这里。
- 气泡没有倒计时。多条消息以 `+N` 提示，点击消息正文或标题可展开全部消息，按时间从旧到新排列；多条时在气泡内滚动，可再次收起。展开/收起不会清除或处理消息；每条可单独关闭或回复。开始回复、关闭输入窗口或发送失败都不会处理原消息。
- 未读/待发记录原子保存到独立文件，不影响等级、形象、用量或任务完成提示。断网和应用退出后重连补收；休眠/关机时不强制唤醒电脑。
- 解除配对不抹掉未读；旧配对待发消息不会转给新朋友。待确认发送按原 ID 重试，避免网络超时造成重复。
- 不配对时不注册、不上传。启用后分享昵称、宠物名字、选中形象和消息；导入的形象只传小尺寸头像。**不传宠物养成、Token 历史、AI 配置**；HTTPS/WSS 加密传输，**非端到端加密**，服务器管理员可以读取消息。

两方都需使用含传话功能的新版 macOS 应用；本机开发版与正式版仍各自独立。服务部署与验证见 [中转运维说明](server/agentpet-relay/README.md)。

### 配对互动与动作预览

在「设置 → 传话 → 预览宠物互动」可选择自己的宠物，模拟收到对方的「戳戳、抱抱、探头」。对方走到身旁，两只宠物在同一地面接触互动，约 3.6 秒后对方离开，自己的宠物恢复待机。噜噜、噜妹使用新增侧身动作；导入宠物保留真实形象，以靠近、倾斜等方式回应。关闭动画或启用 macOS「减弱动态效果」时不播放。

配对后的发送框和传话设置显示对方形象。新互动实时自动播放一次，之后留下「噜妹抱了你一下」这样的独立气泡。点击可无限次本地回放，过期、重启或解除配对后仍能回放；点叉才关闭并标记已处理。多条互动依次自动播放，各自保留气泡，可滚动查看、单独关闭。回放不发送消息或已处理回执。

30 秒有效期只限制自动播放与待发重试，离线旧互动不自动补播。发送互动至少间隔三秒；双方需使用支持互动的客户端。中转协议及六小时清理规则不变，未关闭的气泡不因动画过期而删除。本机预览无需配对、不发送消息。实现与素材说明见 [宠物互动说明](docs/PET_INTERACTIONS.md)。

### 共享屏幕时回窝

右键桌宠，点击「回窝睡觉」，可立即收起所有桌宠、消息及互动气泡、宠物弹窗、菜单栏悬浮气泡和刘海火焰，同时暂停系统通知与提示音。后台收信、消息保存、养成与用量统计继续运行；回窝状态会保留到下次启动。

在 Mac 菜单栏点击 LuMate 图标，选择「出窝搬砖」即可恢复桌宠并查收消息。回窝期间收到的消息不会标记已处理，互动保留可反复点击回放的气泡，出窝时不集中补播。原来的通知、声音与显示偏好保留，出窝后继续生效。

## 数据、连接与联网边界

- **本地统计**：用量历史与养成保存在本机；实时速度与累计用量采用独立通路，不重复记账。功能不要求填写云端模型 API 密钥。
- **开发与正式版隔离**：开发版使用 `local.agentpet.dev.preferences` 和 `~/.agentpet-local-dev/`；本地正式版使用 `local.agentpet.preferences` 和 `~/.agentpet-local/`，两者不会自动迁移。
- **兼容已有设置**：首次运行仅只读导入原 EmberCat 的四类火焰/速度偏好，不覆盖已有 LuMate 设置，也不改写原 EmberCat 配置。
- **不是完全离线应用**：在线宠物浏览和下载仍访问相应资源服务。本仓库不维护原网站服务端或云端用量报表上传；新增的可选双人传话中转独立位于 `server/agentpet-relay/`。
- **不包含个人数据**：源码不附带用户宠物库、真实会话记录、客户端登录信息或模型密钥。备份时还应考虑 UserDefaults 中的偏好和统计，而不只是数据文件夹。
