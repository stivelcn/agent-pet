# images/edits — 噜妹待机动画素材

根据附件1的噜妹原始形象，制作一张六帧的连续待机动画横条。附件1是唯一身份依据；附件2仅用于六个等宽位置的布局，不要画出框线。必须是同一个角色的六个相邻动画帧，不是六种新设计。

六帧从左到右仅排一行，固定正面、全身、同一大小、同一脚底基线，每格一个完整角色，顶部两片叶芽、双耳、裙摆、双脚都不能裁切，各角色之间留出宽阔纯色间隔。画布1536×1024，所有角色在中间同一水平线上，保持六个完整独立的轮廓。

严格保留原图的极大头部和宽圆橙黄色嘴鼻部、黑亮眼睛的形状和位置、嘴角轻微微笑、短圆身体、两片绿色叶芽、橙色果实和奶白圆盘帽檐、奶白荷叶边软帽、浅粉泡泡袖裙、奶白圆领、粉色系带、白纽扣，以及胸口位于画面左侧的小果实布贴。保留柔和精致的3D玩偶材质、颜色和光照。不得变成鸭嘴、缩小嘴鼻部、加头发睫毛、交换布贴方向或改变服装。

动作顺序：第1帧自然睁眼静立；第2帧轻轻吸气，肩部只抬高极少量，眼睛自然睁开；第3帧双眼正在半闭；第4帧双眼完全闭合成自然弧形，脸部、眉毛和嘴巴位置保持不变；第5帧眼睛自然重新睁开，轻轻呼气；第6帧回到与第1帧相近的静立状态，循环无跳变。双脚全程着地，手臂不挥动，不走路，不跳动，身体尺寸变化控制在约1%以内。闭眼需要真实的眼睑表情，不得用一根黑线覆盖仍然睁开的眼睛。

背景必须为完全均匀纯蓝色 #0000FF，以便后期移除；该颜色不得出现在角色内部。全身材质保持不透明。不要透明棋盘格、渐变背景、投影、地面、光晕、发光边缘、动作线、文字、序号、水印、边框或杂点。

## images/edits — 双人互动动作素材

接口：`POST https://api.aimindsky.com/v1/images/edits`，multipart 字段为 `model`、`image`、`prompt`、`size`、`quality`。
模型：`gpt-image-2.6-flare`；尺寸：`1536x1024`；质量：`high`。编辑接口不额外传 `output_format`。
`image` 是从已批准待机图中提取的角色参考；`prompt` 由以下模板、角色约束与动作顺序组合，实际提示词保存在 `model_prompt/pet_interactions/{pet}/{action}/images_edits.md`。后续调用通过 aimindsky-image 技能脚本从钥匙串或 `AIMINDSKY_API_KEY` 读取密钥，禁止放入本文或源码。
这些素材是 LuMate 的四种额外互动片段，不是新的 Codex v2 宠物包；原待机图保持原样。
