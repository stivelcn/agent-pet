# 噜妹：PNG 透明通道接口验证

制作单个正面站立的可爱3D桌面宠物“噜妹”，柔和精致的玩偶式渲染，轮廓圆润清楚，大头短身，双手自然垂在两侧，两只朴素黄色短脚，完整全身。

角色为金黄色身体、饱满宽大的橙黄色嘴鼻部、小圆耳朵，黑亮大眼睛带白色眼白、细弯眉，闭嘴亲切微笑。戴奶白色荷叶边软帽；帽顶是一个橙色果实、两片嫩绿色叶芽和贴着果实的奶白色横向圆盘檐，圆盘不能悬浮。穿浅粉色泡泡袖蓬蓬短裙，奶白色彼得潘圆领，粉色系带蝴蝶结，胸前一个白色圆纽扣和一个小橙色果实布贴，裙底是奶白色细荷叶边。无头发、无睫毛、无鞋子、无额外配饰。

单角色居中，平视镜头，左右对称，1536×1024横向画布，角色完整且四周留空白透明边距。柔和均匀棚拍光，保持脸部、白色帽沿、粉色裙子的不透明材质。

输出要求：真正带 alpha 通道的 RGBA PNG。所有背景像素必须 alpha=0。不要生成灰白棋盘格，棋盘格不是透明。不要白色底、灰色底、彩色底、地面、阴影、文字、水印、边框。只保留角色及干净平滑的抗锯齿边缘，不得通过把白色衣物、眼白和白色帽沿变透明来伪造透明背景。
